# BrandMark

The Kōvara facet mark on its own — three offset planes of one peak, layered so the core reads solid where they overlap.

## When to use
- App icon, favicon, avatar for the Kōvara agent itself, loading states.
- Anywhere the wordmark would be too wide (collapsed sidebar, mobile chrome).

## Tones
- `color` — on light surfaces.
- `on-brand` — white core, for the indigo canvas or photography.
- `mono` / `inverse` — one-color contexts: print, fax, stamps, monochrome partners.

## Example
```tsx
<BrandMark size={32} title="Kōvara AI" />
<BrandMark size={40} tone="on-brand" />
```
