# Eyebrow

The small letterspaced label with the cyan rule that opens a section.

## Rules
- One per section, directly above the heading.
- It names the section's context ("Kōvara portfolio", "Platform", "For developers"); it never
  restates the heading.
- Write it in sentence case — the component applies the caps.
- `onBrand` for indigo or photographic backgrounds.

## Example
```tsx
<Eyebrow>Kōvara portfolio</Eyebrow>
<h2>One team building the next generation of vehicle protection products.</h2>
```
