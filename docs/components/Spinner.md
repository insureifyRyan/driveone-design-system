# Spinner

Indeterminate activity. Inherits `currentColor`, so it reads correctly on any surface or inside any button.

## When to use
- Inline, for work of unknown duration — a carrier rating call, an agent run starting.
- For content that is arriving, prefer `Skeleton`: it holds the layout still.

## Example
```tsx
<Spinner size="md" label="Rating with 4 carriers" />
```
